# **App Name**: KiddiePlan

## Core Features:

- Layout Structure: Two-column layout for calendar and to-do list.
- Calendar View: Calendar view showing weekly schedule.
- Color Coding: Color-coded activity types (school, sport, parties, hobby).
- Child-Specific Rows: Separate rows for each of two children.
- Add events: Add events to a specific date and time for either kid
- Event editor: The event will support title, description and a event type/category.

## Style Guidelines:

- Primary color: Soft blue (#A0D2EB) to create a calming and organized feel.
- Background color: Very light blue (#F0F8FF), almost white, for a clean look.
- Accent color: Muted yellow (#E5BE01) to highlight important events.
- Font: 'PT Sans', sans-serif. Use for both body and headers because of its modern yet warm and friendly feel, which works well with both schedule items and lists of to-dos.
- Two-column layout with the calendar occupying the left side and the to-do list on the right. Calendar rows divided by child.
- Simple, recognizable icons to represent activity types (e.g., school bus for school, soccer ball for sports).
- Subtle animations when adding or completing a to-do item, or when navigating between weeks in the calendar.
